---
title: Build
description: Image build context in deploy.yml.
icon: Hammer
---

`build` selects the Docker context. Paths are relative to the deploy config
file.

String form uses a context directory and the default `Dockerfile` inside it:

```yaml
build: .
```

If the Dockerfile has another name or lives elsewhere, use the object form:

```yaml
build:
  path: ./dev
  dockerfile: ./Dockerfile.dev
```

| Field | Meaning |
| --- | --- |
| `path` | Build context directory. Defaults to `.` when using the object form. |
| `dockerfile` <span className="doc-optional">optional</span> | Dockerfile path. Defaults to `Dockerfile`. |

If `build` is omitted entirely, the context defaults to `.`.

<Callout title="Image tags">
  Elevon tags images from a content hash of files in the build context. It
  applies `.dockerignore` and `.gitignore` next to the Dockerfile when
  collecting those files; git is not required. Changes outside the context do
  not change the tag. If that tag already exists in the registry, the build is
  skipped. Force a rebuild with `elevon build --no-cache`.
</Callout>
